# iPhone 16 Pro Max 真机 VPN 验收

当前均未执行。每项记录构建 SHA/IPA SHA-256、签名环境版本、iOS 版本、PASS/FAIL/未测及脱敏日志；使用用户授权的配置。不要记录真实订阅、密钥、UDID/profile 全文或敏感流量到公开仓库。

## 安装前与并存

- [ ] signed IPA 保留主 App、6 个扩展、必要 Framework/资源；签名及各自 profile 一一匹配。
- [ ] 主 Bundle ID 与已装官方 App 不同，使用独立 App Group，不共享/覆盖官方数据库。
- [ ] 安装过程没有替换/删除官方 App；原 App 可打开，原配置/订阅保持不变。
- [ ] 新 App 正常冷启动、退出重开；Framework 加载无错误；配置空间独立。

## 授权与生命周期

- [ ] 使用非敏感测试配置，首次系统 VPN 授权可正常完成；拒绝/取消有明确反馈。
- [ ] start、连接中取消、连接、重连、停止与系统 VPN 设置中的状态一致。
- [ ] Packet Tunnel 确实以本次 A.extension 启动；不是仅首页显示 Connected。
- [ ] 无效配置/错误节点可恢复，不出现永久假连接状态。
- [ ] 锁屏、后台、前台、应用被系统结束、设备重启后按既有设置恢复；无意外影响官方 App。

## 数据面

- [ ] 代理规则下实际访问目标与出口符合预期；直连规则确实直连。
- [ ] TCP/UDP、DNS、IPv4/IPv6 按配置验证；检查 DNS/IPv6 泄漏与失败回退。
- [ ] Wi-Fi ↔ 蜂窝、断网 ↔ 恢复、弱网下重连可用。
- [ ] 上传/下载速率、服务累计量与实际测试流量一致，断开后不保留旧速率作为实时值。
- [ ] 节点切换、测速、配置更新/服务重载可用；错误节点不会伪装成功。

## 保留功能与资源

- [ ] 本地配置新增/编辑/导入/导出；订阅更新及失败恢复；不公开真实订阅。
- [ ] Share/Action、文件提供、Widget、Intents 各自入口及 App Group 通信可用。
- [ ] iCloud 文件行为在用户已授权容器下验证；无该能力应记录阻塞，不能标为通过。
- [ ] 日志、工具、设置、远程控制及实时统计按实际使用范围回归。
- [ ] 中文/长节点名/大字号与手动 VoiceOver、Reduce Motion 检查。

## 判定

安装成功只证明安装；App 打开只证明启动；系统显示 Connected 只证明生命周期状态。只有相应流量、DNS、IPv6、切网及后台项目实际通过，才能对**这份已签名构建和已测配置范围**声称 VPN 可用。未测项保留未测，不外推全部协议、节点或网络环境。
